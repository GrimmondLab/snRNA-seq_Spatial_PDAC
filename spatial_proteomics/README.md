# Spatial proteomics: MIBI and OPAL

The MIBI and OPAL analyses were done in collaboration with a team at WEHI, using the team's spatial proteomics pipelines: [`sp_segment`](https://github.com/WEHI-SODA-Hub/sp_segment), [`sp_celltype_train`](https://github.com/WEHI-SODA-Hub/sp_celltype_train) and [`sp_celltype_apply`](https://github.com/WEHI-SODA-Hub/sp_celltype_apply). Neither analysis is in the project image or `run.sh`. The raw images, the pipeline settings and the containers are deposited and documented by the WEHI team: *(link TBD)*.
